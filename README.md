# จดประชุม AI · ถอดเสียงและสรุปงานแยกหัวข้อ

เว็บแอปสำหรับถอดเสียงการประชุมภาษาไทย/อังกฤษด้วย Google Gemini API พร้อมสรุปงานแยกหัวข้อ แตกเป็นบอร์ดงาน (Task & Kanban) และสร้าง Mind Map โต้ตอบได้

- **ใช้งานฟรี 100%** รองรับ Google Gemini API รุ่นฟรี (ไม่ต้องผูกบัตรเครดิต)
- **แยกข้อมูลผู้ใช้เด็ดขาด:** ประวัติการประชุม รายการงาน และไฟล์เสียงเก็บอยู่ใน `IndexedDB` ของเบราว์เซอร์แต่ละคน ไม่ปะปนกัน
- **เพิ่มเป็นแอปในหน้าจอมือถือ (PWA):** รองรับการติดตั้งบน iPhone / iPad (Safari -> เพิ่มไปยังหน้าจอโฮม) และ Android (Chrome -> ติดตั้งแอป) พร้อมปุ่มแนะนำ **"เพิ่มลงมือถือ"** บนหน้าเว็บ
- **รองรับทั้งโยนไฟล์เสียงเข้า & อัดเสียงสด:** `.mp3`, `.m4a`, `.wav`, `.webm`, `.ogg`, `.aac`, `.flac`, `.mp4`, `.mov` พร้อมบีบอัดเสียงพูดอัตโนมัติ (32 kbps) และอัปโหลดรองรับไฟล์ขนาดใหญ่บน Vercel Free Tier

## การรันใช้งานบนเครื่องตัวเอง

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` (หากยังไม่ตั้งค่า `.env.local` สามารถกดปุ่ม **"ตั้งค่าคีย์ AI ฟรี"** มุมขวาบนเพื่อกรอกคีย์จาก `https://aistudio.google.com/apikey` ได้ทันที หรือกด **"ดูตัวอย่างสรุปประชุมจริง"** เพื่อทดลองทุกฟีเจอร์)

## การเปิดใช้ฟรีผ่าน GitHub + Vercel (สำหรับแชร์ลิงก์และลงมือถือ)

1. นำโค้ดในโฟลเดอร์ `meeting-summarizer` เก็บไว้บน GitHub (สร้าง Repository แล้ว)
2. เข้าเว็บ [vercel.com/new](https://vercel.com/new) ล็อกอินด้วยบัญชี GitHub แล้วกด **Import** Repository ที่สร้างไว้
3. กด **Deploy** (ไม่ต้องตั้งค่าอะไรเพิ่มก็ใช้งานได้ฟรีทันที หรือจะใส่ Environment Variable `GEMINI_API_KEY` เพื่อเป็นคีย์กลางให้ทุกคนใช้ร่วมกันก็ได้)
4. เปิดลิงก์ `.vercel.app` ที่ได้บนมือถือ แล้วกดปุ่ม **"เพิ่มลงมือถือ"** ด้านบนเพื่อปักหมุดเป็นแอปบนหน้าจอโทรศัพท์
