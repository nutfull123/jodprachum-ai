# ShootNote · สมุดจดสไตล์ GoodNotes & ถอดเสียงประชุม AI

**ShootNote** รวมสมุดจดอิสระแบบ GoodNotes (รองรับ Apple Pencil บน iPad, โน้ตยาว, ShortNote, ตกแต่งสติกเกอร์/โพสต์อิท, แนบรูปและคลิปวิดีโอ/เสียง) เข้ากับระบบถอดเสียงประชุม AI แยกหัวข้อ บอร์ดงาน และ Mind Map ในเว็บแอปเดียว

- **สมุดจดยาว & ShortNote (GoodNotes-Style):** เขียนปากกาแรงกดสมจริงด้วย `perfect-freehand`, โหมด **ปากกา iPad (Palm Rejection)** กันมือโดนและใช้นิ้วเลื่อนหน้าได้, กระดาษ 6 ลาย (`มีเส้น`, `ตารางกริด`, `จุดไข่ปลา`, `ครีมถนอมสายตา`, `Cornell`, `ขาวล้วน`), โพสต์อิท, สติกเกอร์, รูปทรง, แนบภาพ และแนบคลิปวิดีโอ/เสียง
- **แชร์งานทำร่วมกันแบบเรียลไทม์ (ฟรี 100%):** สร้างห้องแชร์สด (`?room=SN-XXXXXX`) ส่งลิงก์ให้เพื่อนเขียนปากกาและแปะโน้ตเห็นเคอร์เซอร์พร้อมกันผ่าน WebRTC (`trystero`) + `BroadcastChannel` โดยไม่ต้องมีฐานข้อมูลเสียเงิน
- **บันทึกข้อมูลในเครื่องอัตโนมัติ:** สมุดจด โน้ต ประวัติประชุม และไฟล์ภาพ/คลิป/เสียงเก็บแยกเฉพาะใน `IndexedDB` ของอุปกรณ์แต่ละคน พร้อมส่งออก/นำเข้าไฟล์ `.shootnote.json` และ PNG
- **ถอดเสียงประชุม AI (Google Gemini):** โยนไฟล์เสียงหรือกดอัดเสียงสด สรุปแยกตามหัวข้อ แตกเป็นบอร์ดงาน (Checklist/Kanban) Mind Map และส่งสรุปเข้าสมุด ShootNote เพื่อเขียนปากกาต่อได้ในคลิกเดียว
- **ติดตั้งเป็นแอปในมือถือ / iPad (PWA):** เปิดบน Safari หรือ Chrome แล้วกด **"เพิ่มลงมือถือ"** เพื่อปักหมุดเป็นแอปเต็มจอบนหน้าหลัก

## การรันใช้งานบนเครื่องตัวเอง

```bash
npm install
npm run dev
```

## การเปิดใช้ฟรีผ่าน GitHub + Vercel

1. เชื่อม Repository **`jodprachum-ai`** บน [vercel.com/new](https://vercel.com/new)
2. *(ไม่บังคับ)* เพิ่ม Environment Variable `GEMINI_API_KEY` เพื่อเปิดให้ทุกคนใช้ถอดเสียงได้โดยไม่ต้องใส่คีย์เอง
3. กด **Deploy** แล้วเปิดลิงก์ใช้งานได้ทันทีทั้งบนคอม iPad และมือถือ
